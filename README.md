# Weatherscope 🌤️

A beautiful, modern and responsive Weather Dashboard built with HTML, CSS & JavaScript.

### ✨ Features

- 🌍 Real-time weather for any city
- 📅 7-Day weather forecast
- 🌡️ Temperature in °C / °F
- 🌙 Dark / Light Mode
- 📍 Multiple city support
- 📱 Fully Responsive (Mobile + Desktop)
- ⚡ Fast & No API key required (using API)
